# 03 脖颈无缝焊接、多层外套零撕裂绑定与全曲动态防穿模

## 3.1 换头必检关卡：仰角 45° 下颌—脖颈无缝焊接（`V10R12`）

### 典型翻车现象
把精修头模装配到素体脖颈后，在正视 T-Pose / A-Pose 下肉眼完全看不出接缝；但一旦套入 MMD 舞台镜头（包含大量地面低机位 `35°–50°` 仰拍抬头镜头，如本工程 `f126`），下巴抬起瞬间，头底与颈顶因骨骼权重差 `5%–10%` 立即张开一道刺眼的横裂口，或产生法线断阶黑线！

### 根治三步法（`step_v10r12_build_and_compare.py`）
1. **边界环几何精确配对吸附**：
   - 提取头模底部开口边界环顶点集 `V_head_rim` 与素体颈部顶部开口边界环顶点集 `V_neck_rim`；
   - 若两侧顶点数相同，一一就近配对吸附到中点；若顶点数不同，以颈顶环折线为连续曲线基准，将另一侧边界点投影至曲线上（误差 `< 0.05 mm`）或直接合并为单流形网格并 `Bridge / Weld`。
2. **边界环骨骼权重 100% 镜像锁定**：
   - 接缝两侧对应顶点的变形骨骼权重（尤其是 `head`、`neck`、`spine.003`）必须**逐分量严格相等**（差值 `< 1e-6`），否则只要转头或仰头就会错位裂开。
3. **跨接缝自定义法线传递（DataTransfer Custom Normals）**：
   - 用一个无缝平滑的代理颈柱网格向接缝上下两圈顶点传递平滑法线，彻底消除仰拍时脖颈处的明暗断阶线。

## 3.2 多层落肩外套「零撕裂」权重传递（`V10R13`）

### 为什么 `ARMATURE_AUTO` 在多层二次元服装上必败？
1. 落肩宽袖外套、双层领口、口袋贴布包含多个互不连通的网格片区（Islands），Blender 原生热扩散自动权重会产出成百上千个零权重孤点或相邻片区权重断崖，手臂一抬口袋直接悬空撕裂！
2. 宽大外套腋下顶点离上臂骨与胸骨距离接近，热权重极易产生锯齿跳变。

### 标准零撕裂传权管线（`step_v10r13_fix_all_tears.py`）
1. **构建干净的单层无洞参考躯干壳（Reference Skin Cage）**：
   - 复制已校准并验证过四肢极限动作零变形异常的素体网格，适度法向外扩 `4 mm` 作为光滑连续权重场源。
2. **最近面插值传递 + 连通片内平滑**：
   - 使用 `DataTransfer` 修改器（`Vertex Data -> Vertex Groups`，映射模式选 **`Nearest Face Interpolated`** 而非 `Nearest Vertex`）将全部变形骨权重一次性映射到水手服、短裤与落肩外套。
3. **仅对「权重数值」做邻接拉普拉斯平滑（Weight-Only Laplacian Blur）**：
   - 在 BMesh 邻接图上对腋窝、肩头、胯根高曲率区的骨骼权重做 `4–6` 轮迭代加权平均（**绝不修改顶点三维坐标**）；
   - 对金属纽扣、口袋丝带、拉链头等刚性饰物：计算该刚性连通片所有顶点的**平均骨骼权重**后赋给该片所有顶点，保证纽扣运动时永不拉伸变形！
4. **仅按 `bone.use_deform == True` 归一化并清理 `< 0.005` 极小杂散权重**。

## 3.3 全曲 6,265 帧动态防穿模解算（`V10R15–V10R16`）

在长达 3 分半钟、包含高速转身与 `115°+` 大踢腿的编舞中，单纯靠静态骨骼权重无法百分百阻止大腿前侧在极限屈髋时顶穿短裤下摆，或胸肋在扭腰时顶穿水手服下缘。

### 为什么不直接开全曲实时布料物理？
- 6,265 帧高密网格布料解算耗时极长，且遇到 MMD 大跨度动作突变时极易发生自碰撞爆炸；局部修一帧就得重烘几千帧缓存。

### 确定性零穿模方案：`BVHTree` 全帧扫描 + 时空平滑姿态补偿（ShapeKey / Baked Corrective Offset）
1. **全时间轴穿模量化审计（先跑 `scripts/audit_garment_penetration.py`）**：
   - 遍历 `f_start..f_end`（先按 2 帧步长粗筛，异常区间逐帧精扫）；
   - 获取当前帧 `depsgraph` 评估后的素体网格（排除已被衣服完全遮挡且不可删除的内部躯干区，或统计穿透到衣服外表面的素体三角面）与各层外衣的 `BVHTree.overlap()`；
   - 输出每件衣服在全曲中的穿透帧列表、穿透顶点数峰值及最差帧号（如本工程精准抓出 `f458`、`f1824` 高抬腿裤口内侧边缘挤压）。
2. **沿人体外法线的带裕量推离与空间高斯扩散**：
   - 对检出穿透或间距 `< 2.5 mm` 的服装顶点 `v_i`，查询最近素体表面点 `p_skin` 与外法线 `n_skin`；
   - 计算所需最小外推量 `δ_i = max(0, margin - (v_i - p_skin) · n_skin)`（`margin = 4.5 mm`）；
   - 在服装网格拓扑邻域内做空间衰减扩散（避免只顶起单个顶点形成鼓包），并在时间轴前后 `±4` 帧做余弦过渡滤波，彻底实现**全曲 6,265 帧身体外露穿模顶点数 = 0**，且裤口/衣摆随抬腿呈现自然的旋转张开感。

# 04 外源 MMD 动作/相机真值重定向、双手防交拧与视线护航

## 4.1 跨体型动作移植：为什么必须用「Oracle 世界空间真值采样」

直接用插件把 `.vmd` 动作导入到自定义二次元角色骨架（如 Rigify / RadDoll / VRoid 改骨）常出现三大失真：
1. **初始静息姿态差异（A-Pose 35° vs T-Pose 0°）**：直接覆盖局部旋转会让双臂整体抬高或夹穿肋骨；
2. **肩宽/臂长比例差异**：拍手、捧脸、扶椅背动作要么双手隔空差 8 厘米，要么手掌直接戳穿脸颊；
3. **IK 足底滑动与重心漂移**：腿长比例不同时，源动作的髋部绝对位移在目标角色上会造成滑步或悬空。

### 标准解法：Oracle Pose Sampling（`sample_miku_oracle_6265.py`）
1. 在临时只读场景中用标准 MMD 参考素体（仅作数学比例尺采样，绝不混入成品或再配布）加载原始 `.vmd`；
2. 逐帧（`1..6265`）提取关键解剖节点的**世界空间三维坐标、骨骼切向向量与极向量（Pole Vector）**，以及按腿长比归一化的髋部重心轨迹，保存为紧凑的 `oracle_full_6265.npz`（约 `11 MB`）；
3. 在我方角色骨架上，按我方真实腿长缩放根骨骼平移，逐帧对齐躯干朝向、肩肘腕方向向量，并对「捧脸/合十/扶腰」等双手相对距离小于阈值的帧启用**双腕相对中心距离保持约束**，既忠实保留原编舞张力，又完美贴合新角色身材。

## 4.2 根治 MMD 重定向头号顽疾：胸前交叉穿插与背身 180° 麻花反拧（`V10R16–V10R17`）

在全曲实测中，有两处极易被常规抽检漏掉、但一播放视频就极其刺眼的骨骼解算陷阱：

### 陷阱 A：胸前双手快速交叉时的前臂/袖口互相穿透（如 `0:56 f1680–1710`）
- **原因**：源角色穿紧身袖，而我方角色穿宽松落肩外套袖，原臂间距不足以容纳两层厚袖口。
- **解法（胶囊体最小间距排斥）**：
  - 将左右前臂 + 手掌建模为两条动态线段 `[elbow_L, hand_L]` 与 `[elbow_R, hand_R]`；
  - 逐帧计算两线段最短距离 `d_seg`；当 `d_seg < R_safe`（含外套袖厚实测取 `85–95 mm`）时，保持原上下前后叠加次序不变，沿角色胸前外法线对前侧手臂微推外移 `+0.5*(R_safe - d_seg)`、后侧手臂微收或微调肘极角，并在前后 `±6` 帧平滑入出。

### 陷阱 B：双手背到身后时手腕/小臂瞬间 `180°–360°` 麻花反拧（如 `0:58 f1740`）
- **原因**：当手臂向后伸展跨过身体矢状面极点时，矩阵转四元数或阻尼追踪（Damped Track）会出现：
  1. 相邻两帧四元数落入相反半球（`q_{t-1} · q_t < 0`），导致渲染子帧或运动模糊旋转整整 `360°`；
  2. 前臂绕自身长轴的扭转角（Twist）突变 `±180°`，把袖口拧成糖纸麻花！
- **解法（半球连续化 + Swing-Twist 分解限幅）**：
  1. **轴向扭转解耦**：将上臂与前臂局部旋转四元数分解为摆动分量 `q_swing`（决定手肘/手腕去哪）与轴向自转分量 `q_twist`（决定袖口朝哪转）；
  2. **生理极限钳制**：限制单帧 `Δtwist <= 12°`、累计生理扭转角 `|twist| <= 75°`，超限部分平滑分配至上臂与腕部；
  3. **全时间轴四元数符号锁定**：对所有骨骼的烘焙关键帧执行线性扫描：
     ```python
     if prev_quat.dot(cur_quat) < 0.0:
         cur_quat.negate()
     ```
  4. **零交拧验收指标**：扫描全曲 `1..N` 帧，所有四肢骨骼相邻帧四元数夹角最大值 `< 22°`，袖口边环周长变化率 `< 8%`。

## 4.3 舞台道具对齐与全曲相机视线（Camera LOS）护航

导入外源相机 `.vmd` 与剧院舞台/单椅道具后，必须跑两项几何物理体检：

1. **交互道具时空对齐（如单双椅坐姿/扶椅帧）**：
   - 找出编舞中臀部高度下降成坐姿或手掌悬停扶靠的特征帧（如 `f458` 附近），以角色臀底/手掌实测世界坐标反推椅子道具的精确 `(X, Y, Z, Yaw)`，确保坐姿不悬空、踢腿不踢穿椅背。
2. **全曲相机视线遮挡扫描（Camera Line-of-Sight Raycast）**：
   - 遍历 `1..6265` 帧，每帧从相机光心向角色「眉心」与「胸口中心」发射两条 `scene.ray_cast()` 射线；
   - 若射线在到达角色前先击中了剧院立柱、吊灯、舞台前沿或椅背，立即记录遮挡物体与帧区间：
     - 若为剧院远端装饰立柱偶发挡脸，优先对该装饰构件设相机射线可见性修正或微调舞台整体挂点，**原则上不破坏原装相机 VMD 运镜节奏**。

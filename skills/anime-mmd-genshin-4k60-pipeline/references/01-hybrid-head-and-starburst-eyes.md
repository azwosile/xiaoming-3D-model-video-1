# 01 混合素体选头、无发帽头皮几何与 4K 星芒角膜眼系

## 1.1 为什么采用「精选四边面头模 + Tripo 发型/衣装」混合路线

在立绘转 3D 实战中，AI 网格生成器（Tripo / Meshy）擅长快速产出复杂的头发分束、外套褶皱与鞋袜配饰，但在**二次元少女/少年面部**上有三大硬伤：
1. 鼻梁、人中、下唇缘等微起伏被三角面噪点淹没，打上三渲二硬阴影后脸颊边缘呈锯齿状；
2. 眼眶内壁与眼球贴合处常粘连成一整块网格，无法独立做虹膜视差凹陷与角膜高光；
3. 张嘴、眨眼形态键（Shape Keys）缺失，强行挖洞补面成本远高于换头。

**实战最优解（V10R1–V10R7 验证）**：
- **面部与素体躯干**：选用拓扑干净、自带标准表情形态键的二次元四边面素体（如 `RadDoll V3 Full`，注意遵守其非商用与禁止再配布协议，文件加 `_PRIVATE` 后缀），以**唯一主原图**为基准做非均匀比例微调。
- **头发与衣装配饰**：保留原图定制生成的发束与衣装，经拓扑清理后精确装配到校准素体上。

## 1.2 头模对原图校准的 4 项硬指标

不要只看正面剪影重叠！必须同时渲染**正交前视、正交左视、正交后视、透视斜 35°（焦距 50–85 mm）**四张图与原图并排核对：

1. **下颌角与下巴尖收束度（Jaw & Chin Taper）**：
   - 通用二次元头模往往偏圆幼或偏宽；若角色设定为清冷/中性少年少女（如《小小小明》），需用平滑比例编辑（Proportional Editing / Lattice）适度收窄下颌支宽度并微调下巴前翘度。
2. **眼位高度与眼间距（Eye Line & Interpupillary Ratio）**：
   - 量测原图「头顶—眼中心—下巴底」垂直比例与「左外眼角—左内眼角—右内眼角—右外眼角」五眼比例，误差控制在 `< 1.5%`。
3. **侧视鼻尖—唇珠—下巴审美线（E-Line）**：
   - 侧视必须检查鼻尖高度与上唇微翘轮廓，这直接决定后续 `Face SDF` 侧面阴影能否打出干净的鼻翼立体感。
4. **废除冗余共享发帽（`GEO-Hair-Cap_Shared`）后的头皮暴露量化**：
   - AI 拆件常多出一层紧贴头皮的厚发帽，容易在额角/耳后穿出黑边。将其隐藏或移除后，必须用 `BVHTree` 统计眼线以上（例如头皮区顶点）到所有发束网格的无符号最短距离：
     - 若存在 `d_min > 3.5 mm` 且法线朝外的头皮暴露区，只对对应发束根部做局部贴合回拉（位移上限 `<= 4 mm`），**严禁对折叠薄片发束使用拉普拉斯平滑**（会把发片压扁漏缝）。

## 1.3 程序化 4K 多层星芒虹膜（`4096×4096`）

低分辨率（`512`–`1024`）画死高光的平面眼贴，在 4K 特写镜头下会显得呆滞浑浊。本工程采用 Python（NumPy + Pillow）程序化合成 **`4096×4096` 七层二次元星芒眼贴**，换角色只需改主色相参数即可在 2 秒内重新生成：

1. **巩膜柔化底（Sclera Base）**：微暖象牙白 `(0.975, 0.968, 0.972)`，外缘带极轻微粉紫血色过渡，避免惨白塑料感。
2. **外虹膜深色环（Limbal Ring）**：外圈高对比深色收边环（宽度占虹膜半径 `7%–9%`，高斯柔化内缘），锁定眼神聚焦力。
3. **上暗下透垂直渐变基底（Upper-to-Lower Gradient）**：上半部压深蓝紫/主色暗调，下半部提亮为通透青蓝/琥珀亮调，形成二次元标志性的「宝石液面感」。
4. **放射状虹膜纤维与星芒碎晶（Radial Fibers & Starburst Flakes）**：在极坐标 `(r, θ)` 下叠加多频正弦放射丝纹与下半月区的细碎高光星点。
5. **瞳孔核心（Pupil Core）**：中心深邃暗核 + 外围一圈微亮虹膜内环（Collarette），增强景深层次。
6. **上眼睑投射软阴影带（Upper Lash Cast Shadow）**：覆盖虹膜上方约 `28%–34%` 弦高，弧度贴合上眼睑曲线，赋予清冷克制的神态。
7. **双主次眼神光底衬（Base Specular Seed）**：保留柔边底衬高光，同时将**最锐利的主高光交给独立 3D 角膜网格**承担。

## 1.4 66 面微凸三维角膜高光壳（`GEO-Cornea_L / R`）

为什么米哈游（原神/崩铁）角色转头时眼睛是「活」的？因为主眼神光不是死画在眼球贴图上的，而是悬浮在虹膜前方的一层微凸结构，随摄像机与头部夹角发生微妙视差位移！

### 标准做法（`V10R19` 实测）
1. **几何构建**：
   - 在左右眼球正前方 `0.8–1.2 mm` 处生成两枚球冠形薄壳网格（各约 `64–66` 个四边面，完全包裹虹膜可视区），命名为 `GEO-Cornea_L` / `GEO-Cornea_R`。
   - 绑定至对应的 `eye.L` / `eye.R` 骨骼（权重 `1.0`），并复刻眨眼闭眼形态键或挂接眼睑遮挡跟随，确保闭眼时绝不穿出眼皮。
2. **着色器设计（EEVEE `BLENDED` / 透明叠加）**：
   - 基于角膜表面法线 `N` 与摄像机视线 `V`（叠加头部朝向偏移的主光方向 `L_eye`）计算半程向量 `H = normalize(L_eye + V)`；
   - 用窄阈值 `ColorRamp`（例如 `0.985 → 0.992`）切出左上主椭圆高光斑与右下呼吸感副星点；
   - 亮斑区 `Alpha = 0.95`（自发光纯白微带天青 `Emission = 1.35`），其余区域 `Alpha = 0.0` 完全透明，且关闭角膜对象的阴影投射（`visible_shadow = False`）。
3. **验收标准**：
   - 渲染正面、左转 `20°`、微仰 `15°` 三张面部特写，确认高光斑相对瞳孔中心产生 `1–2.5 mm` 自然视差滑动，且闭眼帧 `Alpha` 零外漏。

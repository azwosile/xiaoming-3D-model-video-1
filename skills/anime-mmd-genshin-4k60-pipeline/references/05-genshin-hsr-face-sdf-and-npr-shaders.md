# 05 原神/崩铁级 Face SDF、分区色阶与三渲二着色器体系（V10R19）

## 5.1 为什么普通 `Shader to RGB` 在脸部必出「阴阳碎影」？

基础卡通渲染（如直接对面部法线 `N · L` 套两档 `ColorRamp`）在静态正面尚可，但在舞台舞蹈中角色一旦侧转 `25°–75°`：
- 眼窝凹陷、嘴角法令区、鼻翼两侧的真实三维法线会产生细碎、僵硬且不符合二次元手绘美学的杂乱阴影块；
- 若粗暴把面部法线全部球面平滑（Sphere Normal Transfer），又会彻底丧失鼻梁挺拔感与标志性的**「原神式侧光脸颊倒三角亮斑（Rembrandt Anime Cheek Triangle）」**。

**二游工业级标准答案**：**UV 对称展开的 `Face SDF`（有符号距离场阈值贴图）+ 头部局部坐标系逐帧光向驱动**。

## 5.2 从真实头模 UV 生成高精度 `Face SDF` 贴图（`2048×2048`）

无需手绘几十张阴影序列！可通过脚本（参考 `export_face_uv_mesh_data.py` + `generate_v10r19_4k_textures_and_sdf.py`）直接根据当前角色的真实头部 UV 与五官三维坐标程序化生成完美对称的 `Face SDF`：

1. **提取面部 UV 关键解剖锚点**：
   - 从头部网格导出 UV 空间中的 `眉心`、`鼻梁脊线`、`鼻尖`、`左右鼻翼沟`、`左右眼眶上下缘`、`左右颧弓亮区中心`、`嘴唇轮廓` 与 `下巴底缘`。
2. **构建多角度理想二游阴影边界集（`θ ∈ [0°, 180°]`）**：
   - `θ = 0°`（正前顺光）：全脸通透受光（阈值接近 `0.02`），仅鼻底小水滴影与下唇微影保留精致点缀；
   - `θ = 45°–75°`（黄金斜侧光）：背光侧眼下形成圆润饱满的**倒三角柔美亮斑**，鼻梁投射利落折角影；
   - `θ = 90°`（正侧光）：严格沿鼻梁—人中—下巴中轴二分；
   - `θ = 150°–180°`（逆光）：全脸沉入柔和暖粉灰暗部，仅外轮廓留清透边缘光（Rim Light）。
3. **有符号距离场插值合成**：
   - 对每一档角度的二值理想受光掩膜分别用距离变换（Euclidean Signed Distance Transform）转为连续有符号距离场，再沿角度轴做平滑单调积分合成单张 `2048×2048` 灰度阈值图 `SDF_R(u, v)`（右打光）；
   - 左打光直接在着色器内翻转 U 轴采样 `SDF_R(1 - u, v)`（前提：验证面部 UV 左右严格对称；若 UV 不对称，则分别输出 R/G 双通道左右 SDF）。
   - **关键坑点**：在 Blender Image Texture 节点中，`Face SDF` 贴图的 `Color Space` **必须设为 `Non-Color`**，否则 sRGB 伽马曲线会把 `45°` 中间角度的三角光严重压缩变形！

## 5.3 头部局部坐标系锚定与逐帧 `CONSTANT` 烘焙铁律

### 为什么世界空间太阳光方向不能直接喂给 SDF？
在 MMD 全曲编舞中，角色会频繁原地 `360°` 旋转、弯腰、歪头，且相机在 `109` 处硬切镜头间来回瞬移。
必须计算**主光（或以相机前向微偏 `28°` 锚定的审美主光）在 `head` 骨骼局部水平切平面 `(head_right, head_forward)` 上的投影方位角**：

```python
# 逐帧计算头部局部水平光向参数 s ∈ [-1, 1] 与前后向 f ∈ [-1, 1]
head_mat = arm_obj.matrix_world @ arm_obj.pose.bones["head"].matrix
head_right = (head_mat.col[0].xyz).normalized()
head_fwd   = (-head_mat.col[1].xyz).normalized()  # 按具体骨骼轴向校准正前方

# 采用「70% 舞台主光 + 30% 相机审美偏置光」混合，既保留舞台空间感，又防止背身镜头全黑死脸
L_eff = (0.70 * stage_key_dir + 0.30 * cam_key_dir).normalized()
side_dot = L_eff.dot(head_right)
fwd_dot  = L_eff.dot(head_fwd)
```

### 逐帧 `CONSTANT` 插值烘焙铁律
- 将计算出的面部光角自定义属性或材质 Value 节点在 `1..6265` 全曲**每 1 帧打一个关键帧，且将 F-Curve 插值模式全部强制设为 `CONSTANT`**！
- **原因**：在相机瞬移切镜帧（例如 `f415 → f416` 相机从正面瞬切到背后），若使用默认的 `BEZIER` 或 `LINEAR` 插值，Blender 会在子帧或前后切线里产生错误的过冲与慢速扫光感；`1 帧步长 + CONSTANT` 绝对锁定每一帧的精确角度！

## 5.4 `256×20` 多行语义 `Shadow_Ramp`、发丝天使环与五金高光

1. **分区 `Shadow_Ramp`（`256×20` sRGB 色带贴图）**：
   - 不同材质绝不能共用同一种冷灰阴影！按行划分语义通道：
     - **皮肤行**：亮部清透瓷白 → 交界线一抹极窄高饱和暖蜜桃粉红（模拟皮下散射 SSS）→ 暗部通透暖藕粉灰；
     - **白水手服行**：亮部暖白 → 过渡淡冰蓝 → 暗部清澈蓝紫灰（绝不用脏黑灰）；
     - **深色外套/短裤行**：维持色相纯度，暗部略微向群青偏移；
     - **头发行**：配合法线与切向双层色阶。
2. **头发各向异性「天使光环（Angel Ring）」**：
   - 利用发束 UV 纵向 `V` 坐标或骨骼切向结合视线仰角，在头顶黄金高度带（`V ∈ [0.28, 0.36]`）叠加一条随镜头呼吸浮动的手绘感锯齿亮带（强度 `0.18–0.26`，受环境遮蔽压制背光区），瞬间告别塑胶假发质感。
3. **五金配件独立锐利高光（Buttons / Hairpin / Thigh O-Ring）**：
   - 银扣、金属发夹切忌走布料漫反射平涂节点！单独建立金属三渲二材质组：低漫反射底色 + 基于半程向量 `dot(N, H)` 阶跃（`0.92 → 0.96`）的高亮冷银反射斑 + 菲涅尔亮边，让小件五金在 4K 画面里闪烁精致金属光泽。
4. **色彩管理与细描边收口**：
   - `View Transform = Standard`，`Look = Medium High Contrast`，`Exposure = 0.0`；
   - 反转外壳描边采用深紫褐暖暗色，脸部 `0.0007 m`、发丝 `0.0009 m`、外衣 `0.0013 m`，眼周内侧顶点描边权重归零。

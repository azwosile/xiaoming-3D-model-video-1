# 02 Tripo 衣装修身剪裁、口袋黑洞根治与平涂去光重烘焙

## 2.1 Tripo 衣装三大通病与根因定位

直接导入 Tripo 生成的服装网格做动画与三渲二时，几乎必遇以下三类问题：
1. **廓形膨胀臃肿**：为保证网格闭合水密，生成器会把水手服腰围、短裤裤腿和落肩外套整体外扩一圈，套上纤细二次元素体后像套了救生圈。
2. **口袋/褶皱深处出现「死黑破洞」**（`V10R13→V10R14` 经典坑）：远看像贴图画黑了，实则是网格内部生成了深达数厘米的**非流形内折隧道（Inner Tunnel）**与法线翻转碎面，描边修改器（Solidify）在此处向外翻出黑刺。
3. **贴图自带死黑褶皱阴影**（`V10R14→V10R15` 经典坑）：生成器把光影褶皱直接烘焙进了漫反射贴图，叠加三渲二 `Shadow_Ramp` 后变成洗不掉的油污脏斑。

## 2.2 保护不对称设计的修身剪裁（`slim_tailor_garments.py`）

修身剪裁严禁使用全局缩放或镜像重拓扑！必须遵循**「径向收束 + 不对称特征白名单锁定」**流程：

1. **先列不对称特征保护清单**：
   - 以《小小小明》为例：
     - 外套前门襟：**左侧为凸起银色金属圆扣，右侧为竖向缝制扣眼**；
     - 水手服上衣：**仅左胸有贴袋与蓝色丝带饰物**；
     - 配饰：**仅左侧头发别鲸鱼发夹，仅左大腿配金属 O 环腿环**。
2. **高度分段径向收身（Cylindrical / Surface-Offset Slimming）**：
   - 以已校准素体网格构建 `BVHTree`；
   - 对短裤腰臀段、水手服胸腹段按高度区间 `z ∈ [z_min, z_max]` 计算服装顶点到素体表面的有符号距离 `d`；
   - 将冗余空隙从 `25–40 mm` 平滑压缩至分层目标间隙（贴身短裤/内搭 `4–7 mm`，外层落肩外套 `12–18 mm`），同时对纽扣、口袋贴章等刚性微结构采用**整块刚体平移跟随**（同一连通片或局部簇共享同一个平移向量），防止圆纽扣被压扁成椭圆。

## 2.3 口袋黑洞封腔与外套腋下袖窿重拓（`V10R14`）

### 诊断方法
写一个 20 行 BMesh 巡检脚本，专门抓取以下异常面簇：
- 表面法线与局部外凸包朝向点积 `< -0.25` 的内翻面；
- 深度凹入周围邻域均值超过 `15 mm` 且开口极窄的「口袋盲肠腔（Inner Tunnel）」；
- 非流形边（`not edge.is_manifold`）与零面积退化三角面。

### 外科根治步骤
1. **切除盲肠内腔 + 干净桥接封口**：
   - 选中钻进网格内部但镜头永远看不见内底的乱序碎面簇直接删除；
   - 对留下的干净开口环执行 `bmesh.ops.triangle_fill` / `grid_fill`，重新计算外法线（`recalc_face_normals`），并将新封口面的 UV 投射到口袋布料纯色安全区。
   - **效果**：`Solidify` 反转外壳描边瞬间不再往外炸黑刺，口袋边缘呈现干净平整的布料折线。
2. **落肩外套腋下（Armscye）自然悬垂释放**：
   - Tripo 在A-Pose 下生成的落肩外套，袖根下缘与侧胸壁往往粘连成锐角「蹼状死折」，手臂一抬或一垂就会扯出怪异凹坑。
   - 定位腋窝交界区域（`|x| ∈ [0.10, 0.22], z ∈ [1.12, 1.26]`），沿弧线释放底边下垂弧度并做局部切向均匀松弛（Tangential Relaxation），让袖根呈现真实布料的自然弧形折弯而非纸片折痕。

## 2.4 贴图「分位数去光重烘焙」（`rebake_v10r15_clean_textures.py`）

这是从普通 AI 生成质感跨越到**清透赛璐璐平涂质感**的决定性一步！

### 核心原理
AI 贴图中的同一块布料（例如白色水手服或浅蓝外套），亮处是干净的设计本色，褶皱槽里则是烘焙进去的灰黑阴影与环境色杂斑。如果我们直接保留明暗，三渲二的动态光影就无法主导画面。

### 算法步骤（纯 NumPy / OpenCV 像素级处理，不改 UV）
1. **语义色相/材质聚类掩膜**：
   - 在 HSV / Lab 空间内将原贴图自动划分为语义掩膜区：`纯白衣料区`、`冰蓝/主色外套区`、`深蓝领巾/条纹区`、`金属银扣区`、`图案/缝线细节区`（通过局部梯度幅值识别刻意绘制的装饰缝线，予以保留）。
2. **高分位纯净色提取与低频阴影剥离**：
   - 对每块布料区域计算大核高斯模糊（`σ = 24~48 px`）得到「低频烘焙光照场 `L_baked(u,v)`」；
   - 计算该材质簇的 **P82–P88 高分位明度基准色 `C_clean`**；
   - 用除法归一化剥离低频死黑阴影：`C_out = clip(C_in / max(L_baked, ε) * L_target, ...)`，再与 `C_clean` 按 `75%–85%` 比例融合（缝线与丝带边缘保持高锐度）。
3. **UV 接缝膨胀（Margin Bleed / Inpaint）**：
   - 对 UV 岛外缘做 `8–16 px` 颜色外扩填充，彻底杜绝远景 Mipmap 降采样时在衣服拼接缝处渗出黑边！
4. **质检标准**：
   - 将重烘焙贴图单独连到 `Emission (Strength=1.0)` 渲染无光纯平涂（Flat Albedo Pass），全身上衣、短裤、外套应像手绘赛璐璐色卡一样干净均匀，无任何一块擦不掉的灰黑死影。

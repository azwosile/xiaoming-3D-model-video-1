# 二次元角色高阶精修 × MMD 全曲编舞 × 原神/崩铁 4K60 舞台母带全流程

本技能提炼自《小小小明不是小明》从 `V10R1` 到 `V10R19` 共 **19 轮迭代、全曲 6,265 原生帧（3 分 28 秒 83，成片 12,530 帧 @ 60fps）** 的完整实战。
与前置技能 `anime-character-pipeline`（聚焦「立绘拆图 → Tripo 部件生成 → 基础装配 → 24 帧跑步循环 → 基础 Toon18」）互补，本技能专攻**商业番剧/大型二游宣传片级长时舞台 MV 交付**中的七大深水区难题。

> **铁律声明**：文中所列毫米级容差、阈值与色值均为 Blender 5.2 LTS（1 BU = 1 m）下的实测基准；换用新角色或新动作时，必须先跑对应诊断脚本量测，严禁盲套常数。

## 0. 开工前必守的 6 条纪律

1. **任务卡先行**：若当前会话接入 ShunCode / MCP 任务卡工具，每轮开始必须建立或推进任务卡（同一时刻仅允许 **1 个** `in_progress` 步骤，字段名为 `title`），交付回复前必须提交 `completed` 终态快照。
2. **只读红线与里程碑不覆盖**：
   - 用户原图、原始生成包（`.zip`/`.fbx`）、外源 MMD 配布目录（舞台/动作/参考模型）与历史已交付目录**严格只读**。
   - 每轮结构/绑定/材质升级必须另存新里程碑（如 `V10R14` → `V10R15` → `V10R19`），严禁原位覆盖已验收 `.blend`，且移动整理文件时不得破坏 `.blend` 相对贴图与音频路径。
3. **唯一原画优先 + 不对称特征锁死**：
   - 比例、五官气质、配色一律以用户指定的**唯一主原图**为最高真值。
   - 开工前把所有**左右不对称设计**写成硬性检查项（例如：左领侧银扣 vs 右领侧竖向扣眼、仅左侧佩戴鲸鱼发夹、仅左大腿绑 O 环腿环、左胸口袋蓝丝带），严禁镜像修改器一刀切抹平。
4. **先出同机位 A/B 对照图，再跑全量烘焙/渲染**：
   - 任何模型剪裁、穿模解算、面部着色或舞台打光改动，必须先在问题高发帧（如仰角帧、高抬腿极限帧、双手交叉帧、特写帧）渲染升级前后同机位拼图，肉眼验真通过后才允许启动数千帧批处理。
5. **合规分级命名（`_PRIVATE` 物理隔离）**：
   - 凡包含受「禁止二次配布（再配布禁止）」条款约束的第三方素体（如 RadDoll V3、MIHOYO 改造允许模型）或外源 MMD 舞台/动作衍生数据的 `.blend`/`.glb`/缓存目录，文件名统一追加 `_PRIVATE` 后缀并在 `.gitignore` 中硬拦截。
6. **EEVEE 并发与色彩空间铁律**：
   - 同一 `.blend` 或共享贴图目录严禁并发启动多个 EEVEE 进程（会导致纹理锁冲突渲染成品红块）；单机 GPU 分段批处理推荐单进程顺序续渲（带文件大小 `>50 KB` 断点跳过）。
   - 二次元三渲二严禁使用 `AgX` 或 `Filmic`（会把清透肤色压成灰暗脏橘色），必须锁定 **`View Transform = Standard` + `Look = Medium High Contrast`**，成片编码显式写入 **`BT.709`** 色彩元数据。

## 2. 十二条血泪踩坑硬规则（V10R7–V10R19 根治实录）

1. **AI 生成头模扛不住近景特写，果断采用「精选四边面头模 + 原图比例校准 + Tripo 发束精配」混合路线**（`V10R1–R7`）：
   - Tripo / VRoid 原生头模在仰拍或大特写下鼻梁法线破碎、眼眶凹陷。选用拓扑规整的二次元四边面素体头（如 RadDoll V3 Full），按主原图校准下颌收窄度、眼距与眼位高度，并用程序化 `4K` 星芒眼贴 + `66` 面微凸透明角膜壳取代平面画死高光。
2. **换头必查「仰角下颌接缝」：光靠视觉贴合不够，必须做边界环顶点吸附 + `head/neck` 权重完全一致化**（`V10R12`）：
   - 平视正交图看不出脖子接缝，但 MMD 低机位仰拍抬头帧（如 `f126`）会瞬间拉出一条黑缝。必须把头底边界环与颈顶边界环最近邻配对吸附，并强制复制完全相同的 `head`/`neck` 骨骼权重比。
3. **Tripo 衣服「口袋破洞黑斑」的真凶不是贴图黑，而是非流形内陷隧道与法线翻转**（`V10R14`）：
   - 单纯改贴图修不掉口袋处的黑洞。必须进网格拓扑层定位内陷非流形口袋环（`check_inner_tunnel.py`），切除乱序内折碎面后重新桥接封口，并对落肩外套袖窿（Armscye）做平滑松量释放，消除腋下死折粘连。
4. **Tripo 贴图自带烘焙死阴影会毁掉三渲二色阶，必须先做「分位数去光重烘焙」**（`V10R15`）：
   - AI 生成贴图把褶皱灰黑影画死在 BaseColor 里，叠上 Toon Ramp 会变成脏污黑块。必须按材质语义分区提取高分位（P75–P90）亮部纯净主色，保留缝线/纽扣/丝带图案，剥离低频烘焙暗影后再进三渲二节点。
5. **多层落肩外套严禁直接用 `ARMATURE_AUTO`，必须从「已校准素体网格」做距离加权传权 + 权重拉普拉斯平滑**（`V10R13`）：
   - 落肩厚外套离手臂骨骼远、离躯干近，自动权重会导致抬臂时袖口撕裂或腋下炸刺。标准解法：从零撕裂素体表面通过 KDTree / DataTransfer（最近面插值）传递变形权重，再仅对**顶点权重**做 3–5 轮邻接平滑（严禁平滑网格顶点坐标），最后仅对 `deform` 骨归一化。
6. **3 分半钟激烈舞蹈不要硬赌全曲布料解算，用「逐帧 BVHTree 穿透审计 + 姿态驱动法向外推」稳准快清零穿模**（`V10R15–R16`）：
   - 全曲 6,265 帧包含 `115°+` 高抬腿（如 `f458`、`f1820+`）与急速旋转，实时布料极易在快节奏踢腿时炸穿且难以局部返工。对修身短裤、水手服与落肩外套采用骨骼主驱动 + 逐帧 `BVHTree` 穿透检测，在穿透区沿人体外法线施加带余弦衰减的安全裕量外推（`+3~6 mm`），可实现全曲 **`0` 穿模且帧间绝对平滑**。
7. **外源 MMD 动作跨体型移植，严禁直接套骨骼局部欧拉角，必须用「源模型世界空间关节真值采样（Oracle Pose Sampling）」**（`V10R15`）：
   - MMD 模型（如 YYB Miku）初始 A-Pose 角度、肩宽腿长比例与目标模型不同，直接拷贝局部旋转会导致双手插胸或悬空。先在源模型上逐帧采样肩、肘、腕、髋、膝、踝世界坐标与朝向向量（存为 `.npz`），再向目标骨骼反解对齐，才能 100% 还原编舞神韵。
8. **背身双手动作在 `±180°` 极点必发「麻花反拧」，必须加「四元数半球连续性追踪 + Swing-Twist 扭转限幅」**（`V10R16–R17`）：
   - 在双手背到身后的舞段（如 `0:58 f1740`）和胸前交叉舞段（如 `0:56 f1690`），IK/局部求逆极易触发相邻帧四元数符号跳变（`q` 与 `-q` 差 360° 插值反拧）或前臂互相穿透。烘焙前必须强制执行 `if prev_q.dot(cur_q) < 0: cur_q = -cur_q`，对前臂 Twist 分量限幅平滑，并对左右前臂胶囊体施加最小安全距离排斥。
9. **角色 `360°` 走位舞蹈中，世界固定方向的 Toon 光会让脸部阴阳脸碎裂，必须用「头部局部坐标系锚定的 Face SDF」**（`V10R18–R19`）：
   - 原神/崩铁面部清透感的核心不是更亮的灯，而是 **UV 对称展开的 `Face SDF` 阈值图 + 绑定在 Head 骨骼局部水平面上的光向角驱动**。全曲逐帧计算主光在头骨局部系的左右偏角并写入 **1 帧步长 `CONSTANT` 关键帧**，无论角色如何转身或切镜，脸颊始终保持干净利落的二次元鼻翼三角光，且绝不在切镜帧发生慢速旋转拖影。
10. **描边厚度必须随镜头焦距/景别克制微调，且严禁用纯死黑 `(0,0,0)`**（`V10R19`）：
    - 远景好看的 `0.0025 m` 描边推到面部特写会变成粗黑框。面部与五官描边控制在 `0.0006–0.0009 m`，衣装控制在 `0.0011–0.0015 m`，颜色采用染入肤色/环境暖调的**深紫褐色**（如线性 RGB `(0.035, 0.018, 0.028)`），线条精致度立竿见影。
11. **MMD 含大量单帧硬切镜头，直接整段跑 RIFE 补帧必出「跨镜头果冻融化怪帧」！必须先切镜隔离再补帧**（`V10R19`）：
    - 一首 3 分半 MMD 通常有 **100+ 处相机单帧瞬移硬切**（本工程实测 **109 处硬切、112 个连续镜头段**）。若直接把连续 PNG 喂给 RIFE，每处切镜中间都会生成一张上一镜头人脸与下一镜头远景扭曲糊在一起的恐怖融化帧！
    - **唯一正确做法**：先从 Blender 相机时间轴精确提取全部硬切帧（`scripts/extract_camera_hard_cuts.py`），将序列拆成独立的连续镜头段分别跑 `RIFE v4.6`，每个镜头段末尾帧复制 1 帧对齐 `2×N` 帧数（严禁与下一镜头首帧插值），最后无损拼接。
12. **开源展示与大体积母带分发：Git 仓库严控 `<50 MB` 零 LFS，百兆/GB 级 `4K60` 母带走 GitHub Release 分块流式上传**（`Round 32`）：
    - 不要把几百 MB 的 `.blend` 历史或母带塞进 Git LFS（免费配额 1 GB 极易爆仓锁死仓库）。仓库主干只放源码脚本、HTML 交互报告、对比总览图和 `<50 MB` 高压缩预览 MP4；`300 MB–1 GB+` 的 `CRF 19` 真 `4K60` 母带通过 `uploads.github.com` 采用 **`256 KB` 小块流式写入 + 自动删残重传**挂载到 GitHub Release（避免 Windows 大缓冲触发 `WinError 10054` 断连）。

## 3. 核心量化基准速查表（Blender 5.2 LTS 实测）

| 模块 | 关键参数 / 指标 | 实测推荐值 | 备注 |
| :--- | :--- | :--- | :--- |
| **色彩管理** | `View Transform` / `Look` | `Standard` / `Medium High Contrast` | 严禁用 `AgX` / `Filmic`；视频流显式标记 `bt709` |
| **EEVEE 采样** | `taa_render_samples` | `48`（4K 超分源 `1280×720` 或 `1920×1080`） | 配合 `Real-CUGAN models-pro` 边缘极度锐利 |
| **贴图规格** | 眼贴 / `Face SDF` / 分区 `Shadow_Ramp` | 眼贴 `4096²`、`Face SDF` `2048²`、Ramp `256×20` | SDF 贴图色彩空间必须设为 **`Non-Color`** |
| **五金高光** | 银扣 / 发夹 / 腿环 | 独立视角半程向量锐利阶跃 + 暖白边缘光 | 脱离布料平涂，一眼拉开材质贵气感 |
| **描边厚度** | 脸颊 / 发丝 / 服装（反转法线壳） | 脸 `0.0007 m`、发 `0.0009 m`、衣 `0.0013 m` | 顶点组屏蔽眼眶内缘、嘴角与耳道内侧 |
| **硬切检测阈值** | 相邻帧相机瞬移判定 | `|Δloc| > 0.35 m` 或 `|Δrot| > 18°` 或 `|Δlens| > 3 mm` | 导出 `camera_hard_cuts.json` 供 RIFE 分段 |
| **超分与补帧** | `Real-CUGAN` + `RIFE` | `up3x-no-denoise`（`720p→2160p`）+ `rife-v4.6 -u` | 切镜段独立目录输入输出，杜绝跨镜插值 |
| **典藏母带压制** | `libx264` 4K60 / 1080p60 / 仓库预览 | 母带 `CRF 19 -preset slow`；仓库直看 `CRF 26 (<45 MB)` | 压制后必跑 `ffmpeg -v error -i out.mp4 -f null -` |
